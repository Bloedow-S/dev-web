Aula 1 Dev web

O que é Hypertext Markup Language (HTML)?

Linguagem de marcação de híper texto, a mesma estrutura o conteúdo dentro de uma página web não a lógica ou estética.

Como e porquê surgiu o HTML?

Antes do HTML Já havia computadores, redes, arquivos e sistemas para compartilhar documentos. O que não existia era a combinação simples de um navegador + links + URLs + HTTP que conhecemos como Web. O problema era: Como fazer pesquisadores encontrarem e relacionarem informações que estavam em computadores diferentes? Em vez de precisar saber: "O relatório está no computador X, dentro do diretório Y, acessível pelo sistema Z", o html surgiu para possibilitar que um documento pudesse apontar para outro documento por meio de links clicáveis.

O que é eXtensible Markup Language (XML)?

É uma linguagem marcação para estruturar e organizar dados de forma que diferentes sistemas consigam entendê-los e trocá-los.

Qual a diferença de HTML para XML?

Depois do html surgiu o XML porque o html era voltado para apresentar informações, enquanto havia necessidade de uma forma padronizada de organizar, armazenar e transportar dados entre diferentes sistemas.

O que é eXtensible Hypertext Markup Language (XHTML)?

É outra linguagem de marcação de híper texto e foi inspirada no HTML, mas possui uma proposta diferente

Qual a diferença de XHTML para HTML?

O XHTML Foi criada para tornar os documentos HTML mais padronizados, organizados e consistentes. O HTML é Mais flexível e os navegadores toleram alguns erros, já o XHTML Mais rigoroso e o código deve seguir as regras do XML
